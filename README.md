# Single-Node Hadoop and Spark Deployment with Distributed Word Count

A Linux VM deployment exercise installs/configures HDFS and Spark Standalone, verifies NameNode/DataNode and master/worker services, and runs word-count and SparkPi examples. The report also explains Spark execution/storage concepts and operational tradeoffs. This is a single-node laboratory, not a production multi-node deployment.

## Technical highlights

- Configured HDFS and Spark Standalone on a Linux VM and validated storage, worker registration, distributed word count, and SparkPi execution.
- Documented Java/environment configuration, service troubleshooting, and Spark execution/storage concepts.
